ВОЗМОЖНОСТИ

Редактор и движок

Рабочие инструменты без обещаний функций, которых ещё нет в текущей версии.

Studio

WinForms-редактор с иерархией сцены, инспектором компонентов, файловой системой, вкладками скриптов, поиском, терминалом и диагностикой.

2D runtime

MonoGame, объекты и компоненты, физика, коллизии, камера, TileMap, анимации, частицы, освещение и аудио.

Lua

Lua-скрипты выполняются через MoonSharp SoftSandbox. Скрипты редактируются в Studio и запускаются в отдельном Player.

Формат и ресурсы

Проект хранит сцены, объекты, настройки и встроенные ресурсы в JSON-файле .lic. PNG и WAV можно добавлять в проект.

БЫСТРЫЙ СТАРТ

Запуск за три шага

  1. 01

    Скачай и распакуй

    Распакуй ZIP полностью. Не отделяй папки Lic и Player от редактора.

  2. 02

    Открой Studio

    Запусти PixelEngine.Editor.exe. По умолчанию откроется Lic/demo.lic.

  3. 03

    Запусти игру

    Нажми F5. Player откроется в отдельном окне. Shift + F5 останавливает запуск.

Для запуска готового архива .NET SDK не нужен. Требуется Windows x64 и совместимый графический драйвер с поддержкой OpenGL.

СТАТУС

Текущие ограничения

  • Версия preview для Windows x64; редактор использует WinForms.
  • Runtime ориентирован на 2D. Полноценного 3D-редактора пока нет.
  • Lua исполняется в Player; C#-скрипты пока доступны как редактируемый исходный текст, но не запускаются runtime.
  • CI проверяет сборку и headless-тесты. Это не заменяет ручную проверку графики и устройств ввода на целевой машине.
