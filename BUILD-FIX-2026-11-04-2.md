# PixelEngine 2.0 Stage 7 — Prefab and editor startup follow-up

## Fixed

- `LicProjectOperations.CloneObject` now copies `Rotation`, so duplicated objects, scene copies, prefab templates and prefab instances retain authored rotation.
- `CopyObjectData` now copies rotation as ordinary template data.
- Prefab update and revert explicitly preserve each scene instance's X, Y and Rotation overrides while replacing template fields and component data.
- Smoke tests now assert prefab template/instance rotation and report separate failure reasons for instance count, width, component metadata and transform.
- Debug editor builds now use `OutputType=Exe` so `dotnet run --project PixelEngine.Editor` shows startup diagnostics in its console; Release remains `WinExe` (normal GUI app).
- Added `run-editor.ps1`, which builds the editor, starts the actual executable and prints the startup log if it exits early.

## Run on Windows

```powershell
dotnet clean PixelEngine.sln
dotnet restore PixelEngine.sln
dotnet build PixelEngine.sln
dotnet run --project PixelEngine.SmokeTests
dotnet run --project PixelEngine.Editor
```

Or use `powershell -ExecutionPolicy Bypass -File .\run-editor.ps1` for a build-and-launch check with startup diagnostics.

The packaging environment does not have the .NET SDK, so this archive was statically checked only; run the commands above to confirm the Windows build and GUI startup.
