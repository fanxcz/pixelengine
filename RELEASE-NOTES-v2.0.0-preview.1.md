# PixelEngine 2.0.0-preview.1

Первый публичный preview-релиз PixelEngine 2.0 для Windows x64.

## В комплекте

- PixelEngine Studio — WinForms-редактор с тёмной темой, док-панелями и масштабированием DPI.
- PixelEngine Player — отдельное self-contained приложение MonoGame для запуска LIC-проектов.
- Демонстрационный проект Lic/demo.lic и остальные bundled LIC fixtures.
- README с инструкцией запуска, сборки из исходников и известными ограничениями.
- SHA-256 контрольная сумма релизного архива.

## Обновления Stage 13

- Обновлённый интерфейс Studio и адаптивная компоновка.
- Настройки редактора сохраняются между запусками.
- Встроенный PowerShell/CMD терминал с асинхронным вводом/выводом.
- Улучшения диагностики сборки и headless-тесты логики редактора.
- Исправлен запуск packaged-проекта: Studio открывает соседний Lic/demo.lic и запускает bundled PixelEngine.Sandbox.exe без исходной папки и .NET SDK.

## Известные ограничения

- Релизный бинарный комплект рассчитан на Windows x64; Studio использует WinForms.
- Runtime остаётся 2D; 3D workspace выключен.
- C# scripts можно редактировать, но они не исполняются в runtime. Lua исполняется через MoonSharp SoftSandbox.
- Терминал не реализует полный VT100/ANSI и не поддерживает полноэкранные terminal UI приложения.
- CI проверяет сборку и невизуальную логику; ручная проверка графики, DPI и интерактивного UI на нескольких Windows-системах остаётся необходимой.

## Проверки

Релизный workflow выполняет restore, Release build, smoke tests, editor tests и публикацию self-contained Windows x64 файлов. Архив выпускается только после успешного завершения проверок.

Это предварительная версия для проверки и обратной связи, а не заявление о завершённом 3D-движке или полном паритете со старым проектом.
