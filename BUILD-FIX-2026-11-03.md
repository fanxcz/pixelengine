# PixelEngine 2.0 — build fix 2

## Fixed

`PixelEngine.Editor/MainForm.cs` used the unqualified type name `Graphics` in three helper signatures. Because the project also contains the `PixelEngine.Graphics` namespace, the compiler resolved `Graphics` as a namespace rather than `System.Drawing.Graphics`.

The signatures for `DrawObject`, `DrawPolygon`, and `DrawRing` now explicitly use `System.Drawing.Graphics`.

## Verify on Windows

From the repository root:

```powershell
dotnet clean PixelEngine.sln
dotnet restore PixelEngine.sln
dotnet build PixelEngine.sln
dotnet run --project PixelEngine.Editor
```

This source patch addresses the three CS0118 diagnostics reported for `MainForm.cs`. A complete build has not been run in the authoring environment because the .NET SDK is unavailable there.
