# PixelEngine 2.0 Stage 6 — build fixes (2026-11-04)

## Fixed

- Renamed the Scene View panning locals from `dx` / `dy` to `panDx` / `panDy`. This resolves CS0136 because the same method declares `dx` / `dy` later for gizmo dragging.
- Added a null check for `TreeViewEventArgs.Node` before calling `ApplySelectedNode`, resolving nullable warning CS8604.
- Removed the unused `CodeEditorControl.FindRequested` event, resolving warning CS0067. Find remains available from the code editor toolbar and Ctrl+F.

## Verify on Windows

```powershell
dotnet clean PixelEngine.sln
dotnet restore PixelEngine.sln
dotnet build PixelEngine.sln
dotnet run --project PixelEngine.SmokeTests
dotnet run --project PixelEngine.Editor
```

The source archive and patch were checked for ZIP integrity and patch applicability. A .NET SDK is not installed in the packaging environment, so no claim is made that a local `dotnet build` was executed here.
